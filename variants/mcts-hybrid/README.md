# mcts-hybrid

这是一个与 Alpha-Beta 完全不同的轻量根节点 Monte-Carlo 方向：先做必胜/必防和保守的黑棋长连、双三/双四禁手检查，再对每个邻近候选执行固定种子的 28 次短 rollout。rollout 用局部威胁排序加小范围随机抽样，最终按累计回报选点。

特点：单文件 C++17、无外部模型、固定随机种子、每次进程独立；适合比较“采样多样性”而不是深层证明。禁手检测采取保守近似，发现复杂禁手时宁可放弃该黑点。

编译示例：`g++ -O2 -std=c++17 src.cpp -o engine`。输入为 `me` 加 15×15 棋盘，输出一对坐标。
